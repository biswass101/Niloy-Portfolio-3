# Niloy | Portfolio

Personal portfolio website of Naeem Biswass Niloy — Full Stack Developer.

## Tech Stack

- Next.js
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
- Framer Motion

## Getting Started

```sh
npm install
npm run dev
```

## Build

```sh
npm run build

## Production

```sh
npm run start
```
